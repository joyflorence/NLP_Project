# Presentation Guide

This folder contains a presentation-ready guide for the University Academic Semantic Search System.

Files in this folder:
- `01-project-overview.md` - problem, solution, goals, and value proposition
- `02-how-the-system-works.md` - end-to-end system workflow
- `03-architecture-and-models.md` - architecture, tools, NLP models, and technical stack
- `04-demo-script.md` - step-by-step exam presentation script
- `05-exam-checklist.md` - pre-presentation checklist and fallback plan

Recommended order for preparation:
1. Read `01-project-overview.md`
2. Read `02-how-the-system-works.md`
3. Review `03-architecture-and-models.md`
4. Practice with `04-demo-script.md`
5. Use `05-exam-checklist.md` on presentation day
