# Project Overview

## Project Title
University Academic Semantic Search System

## Problem Statement
Universities store many academic documents such as student projects, dissertations, reports, and course materials. Traditional keyword search struggles when:
- users do not know the exact words used in a document
- document metadata is incomplete or inconsistent
- similar work needs to be discovered beyond exact title matching
- large collections become difficult to browse manually

## Proposed Solution
This system provides a semantic search platform for academic documents. Instead of relying only on exact keyword matching, it uses NLP embeddings to find documents that are semantically related to the user query.

## Main Objectives
- Ingest academic PDF documents into a searchable system
- Extract title, author, year, and related metadata
- Support semantic search over indexed documents
- Support preview, download, citation, and similar-document discovery
- Provide an admin workspace for upload, metadata management, indexing, and monitoring
- Support a user library for saving documents for later review

## Target Users
- Students looking for related research or reference material
- Supervisors reviewing past work
- Administrators managing institutional document archives
- Researchers exploring academic literature in the repository

## Core Value Proposition
The main value of the system is that it helps users find relevant academic documents even when the exact keyword does not appear in the title. It also makes institutional document collections more searchable, maintainable, and reusable.

## Key Features
- Semantic search
- Filtering by year and level
- Sorting and pagination
- Preview popup for full text
- Download with signed access flow
- Citation generation in multiple formats
- Save-to-library workflow
- Similar document discovery
- Admin upload and indexing workspace
- Metadata editing and deletion
- Recent ingest activity tracking
